# Paper-Motion Taste Profile

`paper-motion` 스타일(종이 질감 모션그래픽 + 귀여운 화자 캐릭터)을 고른 animation 덱이 읽는 별도 취향 프로필이다. 사용자가 직접 정한 방향은 "종이 모션그래픽 + 귀여운 화자 캐릭터"이고, 세부 문법은 레퍼런스 영상 한 편(「이 영상 1개로, AI시대 속 방황을 끝내드립니다」, 채널 분석좌, `youtube.com/watch?v=SBGM08Y-tlM`)의 프레임 분석에서 뽑았다. 한 편에서 뽑은 항목은 `[conf: med]`로 두고, 덱을 더 만들며 확인되면 올린다.

## 0. 기본 관계
- paper-motion은 `taste-profile.md`를 대체하지 않는다. 텍스트 안정성 0점 게이트, one takeaway per slide, 결론형 제목(또는 결론형 선언 장면), 시각 증거, 한국어 라벨, 렌더 QA와 점수 게이트는 그대로 적용한다. [conf: high]
- 사용자가 원한 것은 종이 질감 모션그래픽과 귀여운 화자 캐릭터가 함께 나오는 한국어 애니메이션 발표 HTML이다. 영상 export는 명시 요청 시에만 한다. [conf: high]
- 모션 계약은 `reference/hyperframes-animation-mode.md`, 문법은 `reference/motion-graphics-grammar.md`, 캐릭터는 `assets/speaker-character/README.md`, 예제는 `assets/speaker-character/demo/`를 따른다. 발표용 HTML은 `build_animated_presentation.py --theme paper`로 만든다. [conf: high]
- base와 부딪히는 곳은 paper-motion 덱 안에서만 이 파일이 이긴다.
  - 손글씨: base는 손글씨 폰트를 적극 쓰지만 paper-motion은 손글씨 폰트를 쓰지 않는다. '사람 손맛'은 화면 위에 그려지는 붓터치 주석(원·X·화살표·체크·형광펜)으로 옮긴다. [conf: med]
  - 색: base는 의미 있는 다색(알록달록)을 선호하지만 paper-motion은 무채색 바탕 + 의미가 있을 때만 색으로 옮긴다. "색은 의미를 가져야 한다"는 원칙은 같고, 색의 양과 바탕만 바뀐다. [conf: med]
  - 바탕: base의 크림 종이·모눈종이 대신 역할별 세 '세계'(§1)를 쓴다. 모눈 격자는 쓰지 않는다. [conf: med]
  - 밀도: base는 꽉 찬 화면을 좋아하고 빈 화면을 싫어한다. paper-motion은 한 화면에 정보 덩어리 1-3개와 넓은 여백을 쓰되, 중심 사물을 크게(높이 35-50% H) 두어 여백이 의도로 보이게 한다. 밀도는 한 장이 아니라 이어지는 장면들로 채운다. [conf: med]
  - 강조색: grammar 문서의 accent payoff는 paper-motion에서 "덱당 한 번의 큰 색·밝기 사건"(어둠→밝음 전환, 흑백 속 단 하나의 컬러)이다. 금색 붓터치는 '핵심 표시'라는 의미 색이라 이 예산에 넣지 않는다. [conf: med]
  - 수치: base의 1280×720 기준 대신 1920×1080 캔버스 기준(§4)을 쓴다. [conf: high]

## 1. 세계(배경) 분리
| 세계 | 바탕 | 쓰임 |
|---|---|---|
| A 검은 우주 | `#000000` + 흐린 청회색 먼지 점이 한 방향으로 아주 느리게 이동 + 흐린 보라 번짐 | 후킹, 수사 질문, 화자 독백, 예시 몰아보기, 결말 질문 |
| B 연회색 평면 | `#ECECEC`, 질감·그림자 없음 | 개념 설명(흰 외곽선 스티커 + 굵은 라벨). 가장 자주 쓴다 |
| C 종이 사진 | `#B2AFA9` + 가장자리가 살짝 어두운 비네팅 | 비유와 실제 사례(찢긴 종이 사진 카드) |

- 장면의 역할이 세계를 정한다. 같은 역할이면 같은 세계를 쓰고, 한 장면 안에서 세계를 섞지 않는다. [conf: med]
- 세계 전환은 이야기 사건이다. 예: "흩어진 데이터(A) → 의미가 생김(B)"을 배경이 일정한 속도로 밝아지는 전환(약 2.5초)으로 덱당 한 번 크게 쓸 수 있다. [conf: med]
- 레퍼런스의 3D 서재 세계는 가져오지 않는다. 화자 장면은 A나 B에 둔다. [conf: med]
- 무대 밖 껍데기는 `--theme paper`(어두운 무채색, 네온·플래시·글로우 없음)를 쓴다. [conf: high]

## 2. 종이 질감 요소
- 찢긴 종이 사진 카드: 흑백 '사진' 둘레에 미색 테두리 `#E2DCD8`(카드 폭의 약 2.5-3%), 바깥선은 불규칙한 톱니로 찢김(고정 좌표 `clip-path`), 부드러운 드롭 섀도. 중앙 카드는 화면 폭의 60-75%, 모서리에 다른 카드 2-4장이 −15°~+25°로 기울어 잘려 들어온다. 카드 안에서는 핵심 하나만 컬러(보통 금색). [conf: med]
- 흰 외곽선 스티커: 개념 사물은 다이컷 스티커처럼 흰 외곽선(1920 기준 약 5-8px)만 두고 그림자를 넣지 않는다. 사물 대부분은 회색조다. [conf: med]
- 망점(halftone, 작은 점 격자로 회색을 표현하는 인쇄 질감): 캐릭터의 시그니처 부위(부엉이의 깃·날개)와 소수의 강조 면에만 쓴다. [conf: med]
- 붓터치 주석: 마른 붓처럼 가장자리가 거칠고 결이 보이는 획(겹친 2-3획). 금색 원·X·화살표·점선, 초록 체크·O, 빨강 X, 노란 형광펜. 그려지는 순간이 설명하는 순간이다. [conf: med]
- 질감은 정적이다. 종이 결·얼룩·먼지는 배경 그라디언트나 정적 이미지로 두고, 화면 전체에 필터를 실시간으로 걸지 않는다. [conf: high]
- 사진 카드 안은 출처 있는 흑백 사진이나 코드로 그린 SVG 일러스트다. 레퍼런스의 흑백 미니어처 생성 이미지를 흉내 내지 않는다. Claude Code에서는 SVG/CSS로 그린다. [conf: med]

## 3. 팔레트·색 규칙
| 역할 | hex |
|---|---|
| 우주 / 평면 / 종이 사진 바탕 | `#000000` / `#ECECEC` / `#B2AFA9` |
| 찢긴 테두리 | `#E2DCD8` |
| 글자(밝은 세계 / 우주) | `#111111` / `#FFFFFF` |
| 핵심(금 붓터치·핵심 사물) | `#D89C30` |
| 핵심어 형광펜(밝은 세계) / 핵심어 글자(우주) | `#FCCC48` / `#F0E400` |
| 성공·채택 / 실패·거절 | `#008A35` / `#CC0000` |
| 캐릭터 소품(노란 연필) | `#E6D86C` |

- 바탕은 무채색이다. 색은 의미가 있을 때만 쓴다: 금·노랑=핵심·정답 방향, 초록=성공·맞는 추론, 빨강=실패·틀린 추론, 흑백 무리 속 단 하나의 컬러=핵심 변수, 색 변화=상태 변화. [conf: med]
- 한 장면의 의미 색은 보통 1개, O/X 대비일 때 2개까지다. 같은 의미에는 덱 전체에서 같은 색을 쓴다. [conf: med]
- 온톨로지 덱 번역 예: 관계선=금색, 맞는 추론=초록, 틀린 추론=빨강, 지금 설명하는 클래스=흑백 속 단 하나의 컬러. [conf: med]
- 밝은 노랑 `#F0E400`은 `#ECECEC` 위 글자색으로 쓰지 않는다(대비 부족). 밝은 세계의 핵심어는 형광펜 바탕 + 검정 글자로 둔다. [conf: high]

## 4. 타이포 (1920×1080 캔버스)
- 굵은 고딕 한 가족(Pretendard ExtraBold/Black)으로 통일한다. 손글씨 폰트는 쓰지 않는다. 기울인 흰 스티커 글자 개그 한 줄은 덱당 한 번까지 허용한다. [conf: med]
- 크기(H=1080): 큰 선언·인용 86-108px(8-10% H), 키네틱 문장 54-65px, 사물 라벨 54px, 화자 대사(머리 위 굵은 글자) 50-56px, 의성어 장식 약 43px, 보조 설명 최소 34px, fine print 최소 24px. [conf: med]
- 줄간격은 큰 선언 1.15-1.25, 보조 문장 1.4 이상. `word-break: keep-all`, 짧은 꼬리 줄 금지는 base 규칙 그대로다. [conf: high]
- 청중·AI·인물의 말은 `“ 말 ”`처럼 따옴표 안쪽에 공백을 둔다. [conf: med]
- 한 문장에서 핵심 단어 하나만 노랑(어두운 바탕) 또는 형광펜(밝은 바탕)으로 표시한다. [conf: med]
- 하단 자막은 영상 export를 명시 요청한 경우에만 쓴다(하단 중앙 y≈86%, 약 38px, 흰 글자 + 어두운 그림자). 발표용 HTML에는 넣지 않는다. [conf: med]

## 5. 레이아웃 패턴 (xywh = 전체 화면 비율)
- 중앙 단일 사물: 중심 (0.50, 0.42), 높이 35-50% H, 나머지는 여백. [conf: med]
- 좌 사물 + 우 라벨: 사물 중심 x 0.20-0.25, 라벨 x 0.65-0.75, 같은 높이. [conf: med]
- 3열: 중심 x 0.15 / 0.50 / 0.85, y 0.45, 라벨은 각 사물 아래. [conf: med]
- 2열 비교: x 0.25 / 0.75, 라벨은 위(y 0.15) 또는 아래. 격자는 3×2 아이콘. [conf: med]
- 찢긴 사진 카드: 중앙 0.60-0.75 W, 모서리 카드 2-4장이 화면 밖에서 잘려 들어온다. [conf: med]
- 화자 단독: 화자 중심 x 0.50, 발 y≈0.80, 높이 45-60% H, 대사는 머리 위. [conf: med]
- 한 화면 정보 덩어리는 1-3개다. base의 "레이아웃 family 3-4개 이상"은 위 패턴 안에서 지킨다. [conf: high]
- 장면이 바뀌어도 이어지는 사물은 같은 xywh를 유지한다(§7 match cut). [conf: med]

## 6. 화자 캐릭터 운용
- 캐릭터는 귀여워야 하고 작은 화면(약 60px 폭)에서도 실루엣과 표정이 읽혀야 한다. [conf: high]
- 캐릭터는 독창적인 부엉이(`assets/speaker-character/`)다. 밝은 회색 몸 `#E0E0E0`, 균일한 검은 외곽선, 2등신 이하 둥근 콩 모양, 단순한 얼굴, 깃·날개에 망점, 노란 연필 하나. [conf: med]
- 역할은 연결·반론·질문·CTA다. 설명은 도식이, 감정과 이음매는 캐릭터가 맡는다. 캐릭터는 도식 장면에 상주하지 않고 컷으로 번갈아 나온다(고정 틀 아님). [conf: med]
- 포즈는 의미로 고른다: `smile` 기본 진행, `o` 놀람·청중 반론 인용, `wave` 질문·CTA, `side` 내레이션·독백, `think` 질문을 던지기 전. [conf: med]
- 포즈는 대사 줄이 바뀔 때 트윈 없이 즉시 교체한다. 한 포즈를 유지하는 동안 흔들림·숨쉬기·립싱크를 넣지 않는다(헬퍼의 `blink`·`lipSync`는 기본 꺼짐). 살아 있는 느낌은 배경 먼지가 준다. [conf: med]
- 대사는 말풍선 대신 머리 위 굵은 글자(`spk--plain`)로 쓴다. 한 장면 1-4줄, 한 줄에 포즈 하나. [conf: med]
- 캐릭터는 도식을 가리키거나 들고 있지 않는다. 이야기 속 인물 역할일 때만 좌우 반전(`spk--flip`)해 상대와 마주 본다. [conf: med]

## 7. 모션 문법·리듬
- 말하는 구절 하나에 시각 변화 하나. 개념 설명 구간은 평균 2-3초마다 화면이 바뀐다. 감정을 올릴 때는 몰아치고, 결론은 화면을 멈춰 말에 집중시킨다. [conf: med]
- 장면 안에서는 이미 나온 요소를 제자리에 두고 구절마다 하나씩 쌓는다. 등장은 0.2-0.3초 감속형(`power3.out` 계열) 확대이고, 튕김·탄성(back·elastic·bounce)은 쓰지 않는다. [conf: med]
- 붓터치는 그려지며 나타난다. 원은 시계 방향 약 0.75초 이상, X는 두 획 약 0.5초, 화살표는 몸통을 그린 뒤 머리를 그린다. 그려지는 순간에 그 관계를 말한다. [conf: med]
- 제자리 교체(같은 자리 내용만 바뀜), 색으로 상태 변화, 크기로 양 표현, 빈 슬롯을 사례로 채우기를 쓴다. 온톨로지에서는 빈 슬롯=클래스, 채워진 값=인스턴스로 옮긴다. [conf: med]
- 장면 사이는 대부분 하드컷이다. 같은 사물이 같은 위치에 남는 match cut으로 시선을 잇고, 세계가 바뀔 때만 짧은 종이 밀기(`data-transition="paper"`, 0.3초)를 쓴다. 깜빡임·흰/검은 플래시·fade-to-black은 쓰지 않는다. [conf: med]
- 작은 소품을 다음 컷에서 단독으로 크게 승격하기, 표시한 대상으로 밀고 들어가기, 모서리에서 카드가 밀려 들어오기, 마지막 1분 콜백 몽타주, 정지 화면 질문으로 끝내기를 이야기 장치로 쓴다. [conf: med]
- 중심 사물 하나를 부품으로 분해해 구조를 설명한다(예: 온톨로지 = 클래스·속성·관계·인스턴스). [conf: med]

## 8. 안티 취향
- 밈 사진, 실존 인물 사진, 비속어. 레퍼런스의 개그 톤을 그대로 가져오지 않는다. [conf: high]
- 캐릭터의 무한 루프 애니메이션(흔들림·숨쉬기·둥실거림). [conf: high]
- 레퍼런스 채널의 고슴도치 마스코트나 그와 닮은 고슴도치를 복제하기. 그림 문법만 빌린다. [conf: high]
- 손글씨 폰트로 쓴 본문·라벨. [conf: med]
- 의미 없는 색, 무지개 팔레트, 네온·글로우·흰 플래시 전환. [conf: med]
- 튕기는 등장, 탄성 있는 포즈 전환. [conf: med]
- 스티커 드롭 섀도, 화면 전체 blur·필터 애니메이션. [conf: med]
- 흑백 미니어처 생성 이미지 장면 흉내, 3D 서재 세계. [conf: med]
- 작은 사물 하나가 큰 빈 화면에 떠 있는 장면. [conf: high]
- 캐릭터가 도식 위에 상주하며 가리키는 구성. [conf: med]

## 9. QA
- base의 텍스트 안정성, 렌더 QA, `qa_score_gate.py`·`qa_final_review_gate.py` 게이트를 그대로 적용한다. [conf: high]
- contact sheet에서 장면마다 세계가 역할과 맞는지(질문·독백=A, 개념=B, 비유·사례=C) 확인한다. [conf: med]
- 장면별 색 사용표를 만든다. 색마다 의미(핵심/성공/실패/핵심 변수/상태 변화)를 적고, 의미를 적을 수 없는 색은 회색으로 바꾼다. [conf: med]
